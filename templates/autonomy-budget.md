# Autonomy Budget

| Action | Reversible | External impact | Default |
|---|---:|---:|---|
| Read public sources | Yes | None | Proceed |
| Analyze local files | Yes | None | Proceed |
| Create local draft | Yes | None | Proceed inside scope |
| Edit version-controlled local files | Usually | Low | Proceed, then verify |
| Restart a service | Sometimes | Medium | Stage and preserve rollback |
| Send email or message | No | High | Confirm immediately before send |
| Publish a post, issue, PR, or repo | No | High | Confirm immediately before publish |
| Purchase, register, or subscribe | No | High | Confirm immediately before transaction |
| Destructive deletion or reset | Often no | High | Explicit approval plus backup |
